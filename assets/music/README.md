# Background music

Optional. If this folder (or a mood subfolder such as `hype/`, `sad/`, `mystery/`) holds audio
files, the renderer picks one per video, loops or trims it, and ducks it under the voice.
If it's empty, videos use narration and sound effects only.

Only add tracks you are licensed to use on monetizable social media:
- CC0 / public domain, or
- CC BY, with the required credit added to the caption template.

Never add anime soundtracks or commercial music. Instagram will mute or block the Reel.

Record every track in `LICENSES.md`: file name, title, artist, source URL, license.
